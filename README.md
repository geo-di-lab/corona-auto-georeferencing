# Corona Auto Georeferencing Setup
This readme will cover the setup of the enviroment so you can use the notebook. The notebook actually goes into details 
on how the code works and the variety of things it can do

For ease of setup, a tool known as uv is utilized to manage  virtual environments effciently. In order to utilize uv, I recommend installing uv globally with the standalone installer, found at the following link https://docs.astral.sh/uv/getting-started/installation/. once uv is installed, open your terminal and cd to project directory and run 'uv sync'. This will handle installing a .venv with the correct version of python and the correct packages and dependencies. From there you can either use 'uv run XXXXX.py' to run python scripts, or you can add the python installation to to your IDE as a local interpreter to use it within the IDE seamlessly.
